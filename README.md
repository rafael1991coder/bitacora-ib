# Bitácora IB

Aplicación estática para registrar recursos de estudio del IB y llevar el progreso individual de varias personas en un mismo navegador.

## Publicar en GitHub Pages

1. Sube este proyecto a un repositorio de GitHub.
2. En **Settings → Pages**, elige **GitHub Actions** como fuente.
3. La acción incluida compilará y publicará el sitio automáticamente con cada cambio en `main`.

Para probarlo localmente, usa `npm install` y después `npm run dev`.

Los datos se guardan en el almacenamiento local del navegador. No se sincronizan entre dispositivos ni navegadores.
