# Bitácora IB

Aplicación estática para registrar recursos de estudio del IB y llevar el progreso individual de varias personas en un mismo navegador.

## Biblioteca compartida

La aplicación utiliza una base de datos en línea: las personas, recursos y marcas de estudio se comparten entre todos los docentes que usen el mismo enlace. El repositorio de GitHub conserva el código fuente.
